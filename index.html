For Teachers: Two Ways to Use This System

Option 1: Teacher Generates Content

  • You configure the API settings (requires API key)
  • You generate content for your lessons
  • You export the content as a JSON file
  • Students import the JSON file - no API key needed!

Option 2: Individual Use

  • Each user configures their own API key
  • Generate custom content whenever needed
  • Perfect for self-directed learners
